软件搬家 · AppMover — 反馈中心

把 C 盘上的软件与数据文件夹安全搬到其他磁盘，并在原位置留下目录联接，让软件照常可用。

这个页面是干什么的

本软件是便携工具，不连接任何自建服务器。所有反馈都通过 GitHub Issue 收集， 所以你的反馈是公开、可追踪、能被长期保存的。

程序内置了报告生成器：遇到没见过的目录名、判定明显不对或 运行报错时，它会生成一份已脱敏的诊断报告，并给出一个预先填好的提交链接。

方式一：在程序里直接反馈（推荐）

程序遇到把握不大的判断时会主动提示。也可以随时手动运行：

上报一个判定有问题的目录

AppMover.exe feedback --path "C:\你的\目录" --open

上报一个运行报错

AppMover.exe feedback --error "错误信息原文" --open

批量上报「规则没见过」的目录名

AppMover.exe feedback --unknown

程序会在自己所在目录下生成 feedback\feedback-时间戳.md 与 .json， 并打印一个 GitHub 提交链接。加 --open 会直接打开浏览器。

报告只包含目录名、路径、判定结果和环境版本， 不读取、不上传任何文件内容；路径中的用户名和计算机名会被替换成 <user> 与 <PC>。提交前你可以在页面上看到全文。

方式二：手工粘贴报告生成提交链接

如果你把报告文件复制到了别处，或者想自己改写内容，粘贴到下面即可生成提交链接。

报告里包含什么

程序版本
用于定位是哪个版本的问题
系统与架构
Windows 版本、x64/x86
是否管理员
判断是否是权限导致的问题
磁盘列表
盘符、文件系统、可用空间
相关路径
已把用户名/机器名替换为占位符
判定与依据
规则为什么给出这个结论
把握不大的目录
最需要人工复核、也是改进规则最需要的数据

不包含

  • 任何文件内容
  • 任何账号、密码、密钥
  • 你的真实用户名与计算机名

提交前请检查

  1. 标题是否能让人一眼看懂问题
  2. 报告里有没有你不想公开的路径（可手工删掉那几行）
  3. 如果是「判定错误」，请补一句正确的判断应该是什么，这比什么都重要
只做 Windows 适配。macOS / Linux 不在支持范围内。
